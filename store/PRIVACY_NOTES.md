# PRIVACY_NOTES.md

Core data flow: JPEG selection, inspection, compression, verification, Save, and Share remain local/on-device.
Network data flow: None required by the core workflow; no INTERNET permission.
AdMob/analytics: Not integrated; no UMP or analytics.
User content sent externally: Not by the core app. Share is explicit and user initiated.
Sensitive data: Testers must use non-sensitive sample images only.
Deletion/reset/export: Original source is preserved; generated copies are separate outputs.
