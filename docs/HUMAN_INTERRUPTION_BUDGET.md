# Human Interruption Budget

Target for a small utility:
- 0 interruptions for compiler errors;
- 0 interruptions for routine test/lint repair;
- 0 manual file transfers between Chat and Codex after repo setup;
- <=1 material scope decision during first vertical slice;
- 1 Artifact Freeze approval;
- 1 production publication approval;
- only unavoidable Play/AdMob account/legal actions.

Repeated human relaying of files/errors means the workflow itself is defective.
