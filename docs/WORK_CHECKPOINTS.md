# ChatGPT Work Checkpoints

W1 Pre-AdMob: spec vs implementation, permissions, privacy, SDK baseline.
W2 Post-AdMob: UMP/consent, ad surfaces, analytics, first-value protection, ad failure/offline.
W3 Play compliance: manifest, Data Safety, privacy, ads declaration, app-ads.txt dependency, listing, screenshots, release identity.
W4 Final readiness: evidence bundle, release artifact, listing truth, policy freshness, residual risk, rollback.

Work never self-authorizes Artifact Freeze or publication.
